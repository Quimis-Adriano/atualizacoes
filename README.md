# Atualizações de firmware — Quimis

Repositório **público** só com as atualizações (o código-fonte é privado).
Os aparelhos leem o manifesto da sua pasta por HTTPS e baixam a imagem anexada à liberação.

| Pasta | Produto |
|-------|---------|
| `q400as-mt/` | Q400AS-MT — pHmetro de bancada pH/ORP/ISE |

Cada pasta contém `manifest-<placa>.json` (versão, endereço, tamanho e SHA-256 da imagem).
As imagens `.bin` ficam nas liberações (tags `<produto>-v<versão>`).
Não publique aqui código-fonte, chaves ou dados de clientes.
